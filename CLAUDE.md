# Numbaz landing page

One-page Numbaz landing page for awareness and waitlist signup (full name and
email). Built from the desktop Figma export. Deployed on Vercel.

## Stack
Next.js (App Router), TypeScript, Tailwind CSS v4 (config lives in CSS:
`app/tokens.css` `@theme`). No database, auth, CMS or animation library.

## Status
Scaffold only; tokens provisional. No sections built, fonts not chosen.
Design exports are in `Design exports/` (local only, gitignored).
